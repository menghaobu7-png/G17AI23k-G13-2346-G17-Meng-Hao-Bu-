# 程式編碼記錄與鎖定

本紀錄保存 PROJECT 2346 本次交易流看板整合的生成程式碼變更，作為專案內部收藏與版本證據。

## 變更內容

- 新增 `tx_flow.json`，定義 `schema_version`、`source`、`currency`、`generated_at` 與 `transactions`。
- 網頁以 `fetch('./tx_flow.json')` 載入交易流資料。
- 將交易流正規化為入金 `deposit` 與出金 `withdrawal`，並渲染到交易流看板。
- 載入失敗時顯示明確錯誤狀態，不以假資料靜默替代。

## 原始載入片段

```js
fetch('./tx_flow.json')
  .then(response => response.json())
  .then(data => {
    console.log('成功載入交易流資料：', data);
    // 在這裡寫入你的渲染邏輯，把資料呈現在網頁看板上
  });
```

## 鎖定規則

此記錄與 `tx_flow.json`、`index.html` 一起納入 Git 版本控制。後續若要修改交易流欄位，請新增版本紀錄，不要覆寫本檔的歷史說明。
